
# Library Management System REST API

## Description
A simple Library Management System using Node.js and Express.js.

## Features
- Add books
- View all books
- View book by ID
- Update book details
- Delete books
- Search books
- Issue books
- Return books

## Technologies
- Node.js
- Express.js
- JavaScript

## Installation
npm install

## Run Server
node server.js

## Server Port
3000

## Storage
Data is stored in a JavaScript array.
No database is used.
